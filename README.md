# 大模型斩杀线与智能选型工作台 (HA-Kill-Zone MiniApp)

> 专为 **Cherry Studio** 打造的桌面端大模型性价比推演与预算配置工作台。

---

## 一、核心特性

1. **大模型性价比散点图与斩杀线交互**：
   - 内置 37 款前沿主流大模型（含 Google、DeepSeek、OpenAI、阿里、腾讯等）的最新跑分与输入/输出计费数据；
   - 动态以性价比基座锚点（当前为 Gemini 3.8 Flash）为基准，将全网模型精准划分为：安全区、走量区、旗舰区与斩杀区（弱且更贵）。
2. **多任务画像与预算核算引擎**：
   - 支持自然语言一句话自动识别任务类型（代码开发、深度推理、长文写作、日常对话等）；
   - 滑块自由配置月度算力预算（5~5000元）与使用强度档位，前端 0.001 秒自动化排布主力与走量组合，并计算结余与超支。
3. **AI 架构师深度诊断与避坑指南**：
   - 原生唤起 `window.cherry.ai.chat`，结合用户的实际业务场景与当前选型方案，输出针对性的技术风险评估、语义缓存优化建议与工程落地避坑方案。
4. **自定义模型补录与 Local-First 持久化存储**：
   - 用户可随时手动录入新发布的模型跑分与价格，通过 `cherry.storage` 永久存在用户本地，实时点亮在散点图中。
5. **一键复制配置全案**：
   - 格式化输出 Markdown 版算力采购与配置方案，方便贴入企业采购文档或团队协作软件。

---

## 二、安装使用说明

### 方式 A：Cherry Studio 在线一键安装（推荐，支持全自动静默升级）
1. 打开 Cherry Studio 客户端；
2. 进入「小程序 / Mini Apps」管理；
3. 点击右上角「从网络安装」，输入以下托管清单 URL：
   ```text
   https://duzhilei951.github.io/ha-kill-zone/manifest.json
   ```
4. 确认权限授权后即可秒级开箱即用。

### 方式 B：本地离线安装
直接在 Releases 中下载最新的 `ha-kill-zone.miniapp`，在 Cherry Studio 中点击「从本地安装」导入即可。
